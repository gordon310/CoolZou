# KIDSPPT

面向中国大陆小学家长的演示稿生成首版。家长上传图片，填写演示稿描述、年级和性别，选择风格后默认直接生成可编辑的 PowerPoint。可勾选“逐页编辑大纲”，检查和修改后再导出；年龄和 PPT 类型已移除。

## 当前可用

- 浏览器预览：完整走通上传、内容大纲、逐页编辑、PPT 导出、作品库和订单记录。
- 原生微信小程序源码：位于 `miniprogram/`，与服务端共用 REST API。
- 本地 `AI_MODE=demo` 按章节整理已有文稿、提取页面要点，完整内容保留到讲者备注，不添加第一人称套话；`AI_MODE=qwen` 已接入 DashScope 多模态生成，但必须先配置完整的服务端密钥、Token 上限和实际账户单价，失败时不会回退为演示内容。
- 生成前可选择 `清新自然`、`活力童趣`、`简洁汇报` 三套 PPT 风格模板。
- 每份作品前 5 页免费；超过 5 页的完整文件固定人民币 50 元。
- 制作及预览页不展示费用提示，仅保留“下载完整版（共X页）”按钮；点击后才展示价格及确认窗口。已购买或不超过5页时直接下载。前5页下载接口保留，页面不再单独展示该按钮。
- 新作品先导出前5页，仅保存后续标题目录；模拟支付后才保存后续正文并导出完整版，前5页保持不变。默认直接导出，勾选大纲编辑时各阶段分别等待确认。
- 试运营限制：账号每日1份新任务，照片内容哈希去重，免费与付费任务各2个执行槽，排版另2槽。高峰20请求使用合成任务验证，不代表正式模型吞吐量。
- 预算账本默认总计5元/日、付费4元/日、150元/月；模拟订单下单前预留0.10元。真实模型按最大输入/输出 Token 和账户单价预留，成功后按 provider usage 结算；费用未知或超过预留时保持占用，不当作零费用。
- 支付渠道选择包含微信支付和支付宝；本地演示只模拟支付，不会扣款。
- 服务端按账号隔离图片、作品、订单和下载链接，上传图片会转为 JPEG 并去除 EXIF。

## 本地运行

需要 Node.js 24。安装依赖后启动：

```bash
npm install
npm start
```

浏览器打开 `http://127.0.0.1:4317`。首次本地运行使用演示账号、演示 AI 内容和演示支付。

运行验证：

```bash
npm test
npm run test:ui
```

## 微信小程序配置

1. 使用微信开发者工具打开 `miniprogram/`。当前 AppID、CloudBase 环境、服务名和腾讯公网域名已经写入公开配置。
2. JSON API 默认使用 `wx.cloud.callContainer`；图片和 PPT 使用 CloudBase 公网域名下载。将该地址加入微信后台的 `downloadFile` 合法域名，无需购买自有域名。
3. 微信登录接口已实现，需配置服务端环境变量 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` 并使用 `APP_MODE=live`。AppSecret 不要提交到代码，也不要发送到聊天中。
4. 真实微信支付和支付宝收款目前保持关闭，完成商户资质、回调域名、签名密钥和官方接口适配后再打开 `PAYMENT_MODE=live`。当前 `live` 模式不会创建演示账号，也不会伪造已收款状态。
5. 真实 AI 配置见 `docs/real-ai-rollout.md`。生产已完成一次隔离的受控真实调用并使用 `AI_MODE=qwen`；`PAYMENT_MODE=disabled` 始终保持不变。CloudBase 公网网关健康检查已恢复，但仍需在不超出每日额度时完成一次真机端到端验收。

完整部署步骤见 `docs/cloudbase-deployment.md`。

## 目录

- `miniprogram/`：原生微信小程序页面和 API 封装
- `server/`：账号、图片、任务、PPT 导出和订单服务
- `web/`：浏览器体验预览
- `docs/spec.md`：产品规格与边界
- `docs/api.md`：接口约定
- `artifacts/`：浏览器验收截图
