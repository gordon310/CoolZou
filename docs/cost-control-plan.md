# 试运营成本控制方案

状态：成本控制基础、DashScope 适配器和合成 provider 验证已在本地实施；生产真实模型调用、真实支付及正式运营上线未启用。
价格核查日期：2026-09-14。用户已确认每天累计约100位家长，其中预计20位购买，高峰约20位同时提交。

## 本次落地与边界

- 新作品：免费阶段持久化前5页正文和全稿标题目录，仅导出免费文件；不超过5页则直接提供完整文件。模拟付款原子写入订单与一个补全任务，补全后才导出完整版。历史作品按旧流程兼容，不删除已有文件。
- 前5页内容冻结；免费文件补全后不重写。选择大纲编辑时，付费阶段仅后续页可编辑，订单版本不随该阶段编辑变动。
- 正式试运营账号每日1个新任务，按北京时间计日；账号内输入和照片内容哈希去重，重复上传同一照片也复用作品。删除作品不归还当日次数。同一账号不能同时新建多个生成任务。本地 `APP_MODE=demo` 且 `AI_MODE=demo` 时放宽为每天20份，仅用于连续验收，不代表线上额度。
- 已完成内容只更换PPT模板时复用已整理内容，仅重新排版，不占用每日AI任务次数；生成独立作品版本，不继承原作品的付款权益。
- 免费、付费各2个执行槽，排版另2槽；SQLite事务领取任务。20个合成请求验证过排队与去重，不代表真实模型RPM/TPM和响应时间实测。
- 整数微元预算账本：总额5元/日、付费4元/日、150元/月，单订单上限0.50元。演示订单按0.10元预留，预算不足不创建订单；演示完成结算0元。待支付预留15分钟到期；已付款和费用未知的预留不自动释放，跨日仍占预算。正式API必须使用保守Token估算代替演示预留。
- 各阶段最多手动重试1次，重试原失败阶段；排版失败不重写内容。进程正常关闭等待执行任务完成，意外中断重启后显示失败，不自动再次调用。
- 免费阶段仅前8张照片参与本地排版选择；最多20张可上传，补全阶段使用其余照片。单张上传不超过1MB，总上传不超过20MB；真实识图尚未实现，不能声称已经理解照片。
- `AI_MODE=demo` 不调用外部模型；`AI_MODE=qwen` 只有在 Key、Base URL、模型、Token 上限、超时和输入/输出账户单价齐全时才启动。Worker 在 provider 请求前预留最大成本，成功按 usage 结算，超预算或 usage 不明保持 `unknown`。
- 已接入：单一 DashScope OpenAI-compatible 多模态适配器、私有 JPEG data URL、JSON Schema slides、usage 成本计算和 Worker 预算门；尚未执行真实 DashScope 请求。付费补全仍因 `PAYMENT_MODE=disabled` 不对线上用户开放，模型选择和实际账户单价需在受控调用前确认。
- 微信开发者工具、真机、供应商账单与生产负载未验证；演示登录可创建新账号，不适用于公开防刷。相同数据目录只允许一个服务进程。

下文保留目标方案和成本测算；凡涉及真实模型和支付的能力仍为待实施目标。

## 推荐方案

免费与付费按生成阶段分开，先生成前5页，收到已验证的支付成功通知后才生成后续页面。免费阶段也使用真正的图文模型，不能回退为固定句式并声称AI生成。

免费体验建议使用北京地域 `qwen3-vl-flash` 的可用赠送额度，开启该模型的免费额度用完即停。付费后使用 `qwen3-vl-plus` 补充理解剩余照片，使用非思考模式 `qwen-plus` 整理正文和讲者备注。这是候选组合，需要以参考广播稿等样例比较效果后确定固定版本。

不依赖第三方永久免费API。赠送额度是试用资源，不是长期成本为零的商业基础。若免费额度耗尽，默认暂停新的免费AI生成，不自动切换到收费模型。开启小额付费补贴应作为后续单独运营决定，建议最高1元/日。

## 免费和付费边界

| 项目 | 免费体验 | 付费完整版，50元/份 |
| --- | --- | --- |
| 生成内容 | 全稿简短目录和前5页正文 | 后续正文、讲者备注、完整PPT |
| 图片理解 | 最多8张，由家长确认参与预览的图片 | 最多20张，只补充识别未处理图片 |
| 生成次数 | 建议每个微信账号每天1个新任务 | 每个订单1次完整生成，含1次局部AI修改 |
| 人工编辑、换配色 | 不调用AI | 不调用AI |
| 重复下载 | 复用已有文件 | 复用已有文件 |
| 异常处理 | 复用任务或有界重试 | 优先重试，最终无法交付则退款 |

正式试运营每天一次已在接口和页面启用；本地演示为每天20份，仅用于验收，未部署上线。付费局部AI修改尚未实现，不在当前购买页面承诺。

按描述先规划全稿主题，避免前5页自成一套后再拼接。保留用户确认过的前5页文字和版式，付费模型沿用目录、语气、照片说明和上下文写后续页面。付费模型不得擅自覆盖用户编辑。已有完整讲稿按原分页整理。实际不超过5页仍提供完整免费下载，不凑页数、不要求购买。

保留“先编辑内容大纲”开关：未选时当前阶段直接导出；选中时在当前阶段内容生成后进入编辑，再确认导出。免费接口只能返回前5页完整内容及后续目录，不提前生成或泄露付费正文。

## 按原价估算

采用北京地域、非思考模式、每次输入不超过所列低价阶梯；不计算赠送额度、缓存折扣或活动优惠。图片折算的Token已经包含在输入用量假设中，不是只算文字。Token不是汉字数。

| 模型 | 每百万输入Token | 每百万输出Token |
| --- | ---: | ---: |
| qwen3-vl-flash，输入不超过32K | 0.15元 | 1.5元 |
| qwen3-vl-plus，输入不超过32K | 1元 | 10元 |
| qwen-plus，非思考且输入不超过128K | 0.8元 | 2元 |

价格来源：[阿里云百炼模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)。具体可用模型和版本以接入时控制台为准。

| 阶段 | 每份用量假设 | 单份费用 | 每日次数 | 每日费用 |
| --- | --- | ---: | ---: | ---: |
| 免费预览 | VL Flash输入10,000、输出2,000 Token | 0.0045元 | 100 | 0.45元 |
| 付费补充识图 | VL Plus输入12,000、输出500 Token | 0.017元 | 20 | 0.34元 |
| 付费文字整理 | Plus输入8,000、输出4,000 Token | 0.0144元 | 20 | 0.288元 |
| 合计 | 每位家长1份，20份付费补全 | | | 1.078元 |

按30天计算约32.34元/月。将模型费用放大3倍作为图片量波动、局部修改和重试的规划余量，为97.02元/月。这些是用量假设，不是已验证单价成本或承诺上限；Token增大、跨阶梯、更换模型和超额重试均需重新计算。

常见100万Token赠送额度，在每次预览12,000 Token的假设下只够约83次，不足一天100次用量。赠送额度一般有90天有效期，但会因使用提前耗尽；主账号和RAM账号共享相应额度。额度优先抵扣和用完即停规则见：[新人免费额度](https://help.aliyun.com/zh/model-studio/new-free-quota)。不能靠增加API Key获得更多额度。

上述估算不包括服务器、存储、下载流量、内容审核、支付手续费、退款和人工客服。基础设施可先以每月100至200元作为采购预算目标，并按实际报价与存储/流量用量确认；不是供应商报价或总成本保证。不在试运营阶段自建GPU推理服务。

## 预算与防重复调用

- 默认免费路径只允许使用赠送额度；额度耗尽或模型不可用时明确暂停。已有文件仍可下载。
- 为后续小额补贴预留免费模型费用1元/日上限，默认不开启自动收费回退。
- 付费生成模型费用建议4元/日上限，模型总预算建议150元/月。单订单模型费用最多0.50元，含局部修改和重试；达到任务上限转人工处理或退款，不无限调用。
- 预算必须在服务器上执行。发请求前，依据输入估算、图片Token规则和最大输出保守预留额度；原子检查“已花费＋正在执行任务预留＋本次预留”是否超限，完成后按实际usage结算。超时且账单未知的调用暂不释放预留；也不能假定取消请求就不收费。
- 免费与付费分账统计，并以服务端订单状态选择模型。两个API Key本身不能隔离账单或替代限额；需要调用权限、模型白名单和预算控制一起约束。
- 微信账号每日配额是主限制，同一账号最多1个正在生成的免费任务。新账号和异常集中请求增加验证；IP限速作为辅助，避免同校家长共用网络被全部拒绝。当前demo登录可无限创建账号，不能直接用于对外免费体验。
- 使用账号ID、内容版本、照片哈希、模型和提示词版本构成任务唯一键；双击、刷新、轮询、重复支付回调复用任务，不重新调用模型。缓存不跨家长账号共享私人素材。
- 图片缩放只用于模型识别；导出保留合适清晰度。识图结果按图片内容缓存，改文字不重新识图，改主题时可复用已确认事实；局部修改只发送所需页面与简短上下文。
- 每个阶段自动重试最多1次，且仍须预算预留。模型成功后排版失败，只重试排版。额度不足、无效输入等错误不盲目重试。
- 设置输入、图片分辨率、输出Token上限，默认关闭思考模式。不使用AI生图或联网搜索来装饰页面。
- 费用报警用于通知，硬预算用于阻断，不能只依赖有延迟的云账单报警。

## 队列与付款

每天100人不等于100个任务同时执行。当前免费和付费各2个执行槽，排版另设2槽。高峰20人提交时接受排队；正式模型接入后还须依据RPM/TPM配额和实测调整，不承诺未经实测的等待时间。

下单前检查可交付性并预留付费任务预算。预算不足时暂停新订单；已经收款的订单使用已有预留完成交付，不能被免费任务挤占。支付成功只改变购买状态，不代表文件已经生成成功；UI需分别显示已付款、生成中、可下载和退款状态。

支付回调必须验签并核对订单、金额和内容版本；一个订单只能触发一次补全任务。系统失败最终不能交付，进入退款处理，不能用低质量演示结果冒充付费交付。

免费未购买素材建议保留7天，付费文件建议保留30天并提前说明下载期限。删除策略只适用于未来明确告知的试运营数据，不在本次方案中删除现有文件；订单记录与文件保留规则分开。

3. 接入正式登录与可验证的支付通知，再开放收费补全。当前AI与支付均为演示配置。
4. 用合成调用测试额度边界、并发抢额度、超时、重复回调和重试；先不消耗真实API额度。
5. 最后用少量已授权素材实测实际Token、每份成本、图片对应、主题完整度、文笔和排版，再扩大免费体验人数。模型便宜不能成为再次降低文案质量的理由。
