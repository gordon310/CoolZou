# CloudBase 安全网关设计

## 目标

微信小程序不使用自有域名，通过微信云托管访问轻量服务器上的现有 CoolZou 后端。轻量服务器继续保存作品数据并完成 AI 和 PPT 生成。

## 数据流

1. 小程序使用 `wx.cloud.callContainer` 调用 JSON API。
2. 云托管网关仅允许 `/api/`、`/download/` 和 `/health`，并为上游请求附加专用密钥。
3. 网关通过校验服务器证书的 HTTPS 连接访问轻量服务器。
4. 图片由小程序通过云托管公网域名下载为临时文件后展示。
5. PPT 通过云托管公网域名流式下载，并继续使用现有短期下载票据和用户令牌。

## 安全边界

- `GATEWAY_SECRET` 必须在 CloudBase 和轻量服务器中分别作为环境变量配置。
- 上游服务器证书私钥只保存在服务器。
- 网关只保存上游 CA 公钥的 Base64，不关闭 TLS 校验。
- 轻量服务器在配置网关密钥后拒绝无密钥的 `/api/` 和 `/download/` 请求。
- 小程序源码只包含公开的环境 ID、服务名和腾讯公网域名。

## 运行模式

- 本地开发：继续使用 `http://127.0.0.1:4317` 和 `wx.request`。
- 云端运行：使用 `callContainer` 处理 JSON，使用云托管公网域名处理二进制下载。

## 验证标准

- 网关正确转发方法、路径、查询参数、请求体和响应状态。
- 网关不转发外部 `Origin`，并覆盖任何伪造的网关密钥。
- 生产环境拒绝 HTTP 上游。
- 后端配置密钥后拒绝缺失或错误密钥。
- 小程序云端请求自动包含服务名和登录令牌。
- 图片与 PPT 下载都通过云托管公网域名。
- 全部现有测试继续通过。
